# OpenCV Basics

This project demonstrates the fundamentals of image processing using OpenCV in Python. It covers reading, displaying, resizing, and working with images, making it a good starting point for learning computer vision.

## Tools Used

- Python
- OpenCV
- NumPy

## Topics Covered

- Read an image
- Display an image
- Resize an image
- Work with image arrays
- Basic OpenCV functions

## Project Structure

```
Open CV/
│── Read and Show an Image using OpenCV.ipynb
```

## How to Run

1. Clone the repository.
2. Install the required libraries.
3. Open the notebook.
4. Update the image path if needed.
5. Run the notebook.
