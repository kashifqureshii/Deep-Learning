# Stock Market Prediction

This project uses deep learning to predict stock prices based on historical market data. It covers data preprocessing, visualization, model training, and prediction using an LSTM neural network.

## Tools Used

- Python
- TensorFlow
- Keras
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Project Workflow

- Load historical stock market data
- Preprocess and normalize the dataset
- Create training sequences
- Build an LSTM model
- Train the model
- Predict stock prices
- Compare predicted and actual values

## Project Structure

```
Stock-Market-Prediction/
│── Main.ipynb
```

## Results

The model learns patterns from historical stock prices and generates predictions based on previous market trends.

## How to Run

1. Clone the repository.
2. Install the required libraries.
3. Open `Main.ipynb`.
4. Run the notebook from start to finish.
