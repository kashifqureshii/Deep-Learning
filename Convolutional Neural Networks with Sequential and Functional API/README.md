# MNIST Classification using Keras Functional API

This project demonstrates how to build a neural network using the Keras Functional API to classify handwritten digits from the MNIST dataset. It covers data preprocessing, model creation, training, and evaluation.

## Tools Used

- Python
- TensorFlow
- Keras
- NumPy

## Project Workflow

- Load the MNIST dataset
- Preprocess and normalize the images
- Build a neural network using the Functional API
- Train the model
- Evaluate model performance

## Project Structure

```
MNIST-Classification-Using-Functional-API/
│── Main.ipynb
```

## Results

The model learns to classify handwritten digits (0–9) and achieves high accuracy on the MNIST test dataset.

## How to Run

1. Clone the repository.
2. Install the required libraries.
3. Open `Main.ipynb`.
4. Run the notebook.
