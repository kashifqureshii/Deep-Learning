# Brain Tumor Detection

This project uses a Convolutional Neural Network (CNN) to detect brain tumors from MRI images. The model is trained using TensorFlow/Keras and saved for future predictions.

## What this project does
- Loads MRI images
- Preprocesses the data
- Trains a CNN model
- Predicts whether a tumor is present

## Files
- `Main.ipynb` – Model training
- `Load and use Model.ipynb` – Load the saved model and make predictions
- `brain_tumor_cnn_model.h5` – Trained CNN model

## Tools Used
- Python
- TensorFlow / Keras
- NumPy
- Matplotlib

## Goal
The goal of this project is to learn how deep learning can be used for medical image classification.
