# Handwritten Digit Recognition

This project uses a Convolutional Neural Network (CNN) to recognize handwritten digits from the MNIST dataset. The model is trained using TensorFlow and Keras and can predict digits from unseen images.

## Tools Used

- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib

## Project Workflow

- Load the MNIST dataset
- Preprocess and normalize the images
- Build a CNN model
- Train and evaluate the model
- Predict handwritten digits

## Project Structure

```
Handwritten-Digit-Recognition/
│── Main.ipynb
```

## Results

The model achieved approximately **98.9% test accuracy** on the MNIST dataset and can correctly classify handwritten digits from 0 to 9. :contentReference[oaicite:2]{index=2}

## How to Run

1. Clone the repository.
2. Install the required libraries.
3. Open `Main.ipynb`.
4. Run the notebook from start to finish.
