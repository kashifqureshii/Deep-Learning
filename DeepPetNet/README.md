# Cats vs Dogs Image Classification

This project uses a Convolutional Neural Network (CNN) to classify images as either cats or dogs. It covers image preprocessing, model training, and prediction using TensorFlow and Keras.

## Tools Used

- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib

## Project Workflow

- Load training and testing images
- Preprocess images using ImageDataGenerator
- Build a CNN model
- Train the model
- Predict whether an image is a cat or a dog

## Project Structure

```
Cats-vs-Dogs-Classification/
│── Main.ipynb
```

## Results

The model learns features from images and predicts whether the input image belongs to a cat or a dog.

## How to Run

1. Clone the repository.
2. Install the required libraries.
3. Update the dataset paths.
4. Run the notebook.
