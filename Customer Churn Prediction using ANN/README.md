# Customer Churn Prediction using ANN

This project uses an Artificial Neural Network (ANN) to predict whether a customer is likely to leave a company based on customer information. It demonstrates the complete deep learning workflow, from data preprocessing to model training and evaluation.

## Tools Used

- Python
- TensorFlow
- Keras
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Project Workflow

- Load and explore the dataset
- Preprocess and encode the data
- Scale the features
- Build an ANN model
- Train and evaluate the model
- Predict customer churn

## Project Structure

```
Customer Churn Prediction using ANN/
│── Main.ipynb
```

## Results

The model learns customer behavior from historical data and predicts whether a customer is likely to churn. This project is a simple example of applying deep learning to a business problem.

## How to Run

1. Clone the repository.
2. Install the required libraries.
3. Open `Main.ipynb`.
4. Run the notebook from start to finish.
